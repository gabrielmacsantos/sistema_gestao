## Brand & Style

This design system sets the standard for high-trust personal wealth and expense intelligence in a refined dark mode environment. The visual narrative combines modern Swiss precision with understated luxury fintech cues: sharp mathematical layout, calm negative space, and deep atmospheric depth.

### Visual Aesthetic & Philosophy
- **Style:** Precision Minimalist with Atmospheric Translucency (Dark Mode).
- **Core Mood:** Discerning, disciplined, effortless, and financially secure.
- **Emotional Response:** Empowers users with a feeling of absolute control over complex cash flows while minimizing eye strain during extended analytical sessions.
- **Surface Strategy:** Deep slate and navy panels suspended over a quiet obsidian-navy canvas, delineated by subtle translucent borders and crisp, high-contrast light typography.

## Colors

The dark mode palette pairs deep slate and navy foundations with luminous cyan/teal and emerald performance accents, ensuring effortless legibility and low-glare contrast.

### Roles & Harmonies
- **Primary (`#14B8A6` / `#0D9488` - Cyan/Teal):** Directs the primary flow, active states, key interactive controls, and financial accumulation markers. `#0D9488` anchors solid filled buttons with crisp white text, while `#14B8A6` provides high-contrast interactive highlights, icons, and focus rings on dark surfaces.
- **Secondary (`#94A3B8` - Cool Slate):** Anchors secondary typography, muted metadata, and structural iconography against deep navy backgrounds.
- **Tertiary (`#10B981` - Growth Emerald):** Strictly communicates positive cash flow, matched budgets, and verified receipt attachments.
- **Neutral & Surface Hierarchy:**
  - **Base Canvas (`#0B111E`):** Deep obsidian-navy background that eliminates harsh glare.
  - **Card Surface (`#111A2E`):** Primary container plane for metric cards, ledgers, and data panels.
  - **Elevated Surface (`#17233B`):** Interactive hover states, active navigation items, and raised popover planes.
- **Text Hierarchy:** Crisp off-white (`#F8FAFC`) for primary headings and balances, `#CBD5E1` for body copy, and `#94A3B8` for secondary labels.
- **Critical Accents:** Luminous Rose (`#F43F5E`) reserved strictly for deficit markers, subscription alerts, and overdue categorizations.

## Typography

Typography establishes an immediate hierarchy between high-value financial telemetry and narrative transactional history, rendered in high-contrast light ink (`#F8FAFC` and `#CBD5E1`) over dark slate surfaces.

- **Primary Structure:** Plus Jakarta Sans delivers contemporary precision for macro numbers, net worth metrics, and main module headers.
- **Functional Body:** Inter handles the information density required for ledger tables, expense logs, and status readouts.
- **Tabular Numerics:** All currency, percentage shifts, and ledger entries must utilize tabular figures (`font-variant-numeric: tabular-nums`) to maintain vertical alignment down balance sheets.

## Layout & Spacing

The layout is built on a responsive 12-column fluid framework governed by an 8-point geometric scale.

### Breakpoints & Canvas Flow
- **Mobile (< 768px):** 4 columns. Edge-to-edge cards with `margin: 1rem`. Bottom navigation replaces side rails. Quick transaction actions move to a sticky base container.
- **Tablet (768px – 1024px):** 8 columns with `margin: 1.5rem`. Side navigation collapses into an icon dock. Split views for categories and details become vertically stacked modules.
- **Desktop (> 1024px):** 12 columns with `margin-desktop: 2.5rem` and fixed left command rail (260px). Main metrics span 3-4 columns, ledger tables span 8 columns, and secondary expense breakdowns occupy the remaining 4 columns.

## Elevation & Depth

In dark mode, depth is established via tonal surface stepping, subtle translucent borders, and frosted overlays rather than heavy drop shadows.

- **Surface Tiers:**
  - `Tier 0 (Base Canvas):` Solid `#0B111E`.
  - `Tier 1 (Cards & Data Panels):` `#111A2E` framed by a 1px translucent border (`rgba(255, 255, 255, 0.08)`).
  - `Tier 2 (Sticky Headers, Elevated Panels & Filters):` Frosted `#17233B` (`rgba(23, 35, 59, 0.82)`), backed by a `12px` Gaussian blur and a 1px translucent border (`rgba(255, 255, 255, 0.12)`).
  - `Tier 3 (Floating Overlays & Modals):` `#17233B` with an ambient dark shadow (`0px 20px 25px -5px rgba(0, 0, 0, 0.45), 0px 8px 10px -6px rgba(0, 0, 0, 0.35)`), paired with a deep translucent backdrop scrim (`rgba(5, 8, 15, 0.7)`).
- **Hairline Precision:** Every structural container uses subtle, low-opacity light borders to separate dark planes cleanly without visual heaviness.

## Shapes

The shape system leverages a refined 8px baseline curvature (`roundedness: 2`). This curve softens heavy numeric structures without sacrificing the clean, professional geometry needed for analytical fintech tools.

- **Containers & Panels:** `16px` (`rounded-lg`) for major visual modules, financial summaries, and metric containers.
- **Interactive Controls:** `8px` (`base`) for buttons, text inputs, search fields, and contextual dropdowns.
- **Badges & Tags:** Fully curved pill geometries for operational status badges, category chips, and receipt tags to contrast with square metric cards.

## Components

### Buttons
- **Primary:** Background `#0D9488`, label `#FFFFFF`, borderless, 8px corner radius. Subtle hover state to `#14B8A6` with a micro-scale transition (`transform: scale(0.99)`).
- **Secondary:** Surface `#17233B`, border `1px solid rgba(255, 255, 255, 0.12)`, label `#F8FAFC`. On hover: surface transitions to `#1E2D4A` with border `rgba(255, 255, 255, 0.2)`.
- **Tertiary / Destructive:** Muted rose background (`rgba(244, 63, 94, 0.14)`), label `#FDA4AF`, hover to `#F43F5E` with label `#FFFFFF`.

### Expense Status Badges
- Built as pill shapes with `label-sm` typography and a micro dot indicator (6px).
- **Cleared / Paid:** Emerald wash (`rgba(16, 185, 129, 0.14)`), dot & label `#34D399`.
- **Pending:** Amber wash (`rgba(245, 158, 11, 0.14)`), dot & label `#FBBF24`.
- **Disputed / Flagged:** Rose wash (`rgba(244, 63, 94, 0.14)`), dot & label `#FB7185`.

### Input Fields & Search Bars
- Background `#0B111E`, 1px translucent boundary (`rgba(255, 255, 255, 0.12)`), 8px border radius, text `#F8FAFC`, placeholder `#64748B`.
- Padding: `0.625rem 0.875rem`. Focus ring: `2px solid #14B8A6` with `0px` shadow offset.
- Numeric inputs always feature prefix/suffix currency symbols set in static `#94A3B8`.

### Ledger Lists & Transaction Rows
- Compact layout rhythm (56px row height desktop, 64px mobile).
- Border-bottom: `1px solid rgba(255, 255, 255, 0.06)`.
- Hover style: Complete row shifts to `#17233B` smoothly with active cursor.
- Category icon: Centered inside a 36px rounded-full teal/slate wash container (`rgba(20, 184, 166, 0.12)`) to the left of the merchant name.

### Receipt Attachments
- Compact thumbnail preview (40x40px) with 6px border radius, enclosed in a 1px border (`rgba(255, 255, 255, 0.12)`).
- Unattached state: Subtle dashed border (`1px dashed rgba(255, 255, 255, 0.2)`) displaying a micro clip icon in `#94A3B8`, transforming on hover to `#14B8A6` dashed stroke and icon.

### Metric Cards
- Background `#111A2E`, 1px border (`rgba(255, 255, 255, 0.08)`), radius `16px`, inset padding `1.25rem`.
- Features metric header (`label-md` in `#94A3B8`), numeric balance (`numeric-metric` in `#F8FAFC`), and trailing trajectory pill showing comparative weekly delta.
